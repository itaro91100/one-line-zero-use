One line describing a hilariously useless superpower. Entry for make.fun's "One Line, Zero Use: The Useless Superpower Sprint" bounty, $5 in USDC.

## The line

> I can teleport anywhere in the world — as long as it’s the exact spot I’m already standing on.

94 characters, one line. Teleportation is the ultimate superpower — until the fine print limits it to the exact spot you're already standing on, which makes it perfectly, hilariously useless. It fits the brief exactly: one original line, one useless superpower, tight wording, no setup needed.

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt`.
